# Rune Factory 4 Special — Elemental Absorption Brooch Build Guide

A visual build guide for creating **Fire, Water, Wind, Earth, and Light absorption brooches** in Rune Factory 4 Special.

The key idea is simple:

**Add Object X first, then add one matching resistance-reduction material during crafting.**

For Wind, Earth, and Water, finish the build with two post-craft upgrades using the same material.

## How to use the guide

1. Choose the element you need.
2. Follow that element's line from the brooch to the final absorption result.
3. Keep **Object X first** in the crafting order shown.
4. Apply the post-craft upgrades only where the stream includes them.

The “one matching material” message refers to the matching material added **during crafting**. Wind, Earth, and Water still require the two post-craft upgrades shown in their streams.

## Need a Disastrous Dish?

The Light build uses a Disastrous Dish. If you do not have one, buy about 50 Turnip Seeds and cook them in bulk with **Do not use recipe**. If needed, cook the resulting Failed Dishes again for another chance.
