## 本編クリア直後に揃えるもの

本編直後から20階を目指すなら、**ウインターロッドで先に14階へ行き、竜幻石を取ってからマジカルステッキへ更新**する進め方があります。実践条件は引継ぎあり・ハード・DLCスターターセット使用です。クリア前の準備は[春のうちに本編をクリアする方法](rf5-spring-story-clear.html)を参照してください。

| 準備 | 目安 |
| --- | --- |
| 突入用の杖 | ウインターロッド。まず14階まで戦える状態にする |
| 攻撃魔法 | ガトリングコメットを用意。装備してRPと持ち替えを確認 |
| アクセサリー | 不戦のロザリオと、必須戦闘用のアクセサリー |
| 武器製作 | マジカルステッキのレシピ（鍛冶Lv76）。10倍鉄の強化まで行うならLv96を目安に調整 |
| 強化素材 | 歌の小ビンと10倍鉄。入手済みの防具・回復品も持参 |

レシピが足りない場合は、使えるレシピパンで習得を進めます。高難度レシピには武器上級レシピパンが必要になることがあるため、手元になければ迷宮のボス報酬も利用します。実践では本編クリア後に一晩かけ、スキル上げ、パンの確保、歌の小ビンと10倍鉄の収集を行ってから突入しました。鍛冶のほかに装飾品も更新する場合は、必要な細工スキルを別に見てください。

## 14階で折り返してから20階へ

1. **ウインターロッドで14階を目指す。** 道中は不戦のロザリオを使い、通過できる戦闘を省きます。ボスや必須部屋の前では戦闘用の装備に切り替えます。
2. **14階で竜幻石を確保する。** 取れたら一度リグバースへ戻り、マジカルステッキを作ります。レシピに必要な残りの材料は、オリハルコン、愛のうろこ、愛の結晶、棒・茎類です。所持欄とレシピを先に確認しておくと折り返しが一度で済みます。
3. **歌の小ビンの直後に10倍鉄を使う。** 上位杖の魔攻を補ってから再突入します。実践で使ったレアなあきかんは、火力を出す工程やクリアの必須条件に含めません。
4. **必須戦闘はガトリングコメットで処理する。** 敵の隙や射線を見て、攻撃が当たる距離から撃ちます。被弾が問題なら武器をさらに厳選する前に、封印対策・回復・防具を見直します。消耗が大きければ一度帰還して立て直します。

この実践では**春29日のゲーム内午前1時34分ごろに20階をクリア**しました。時刻は作中の時計で、鍛冶や素材収集の事前準備もあります。同じ日付を狙う場合も、まず14階までと杖更新後の二つに分けて計画すると進めやすくなります。

## 先に仕上げなくてよいもの

最初から最終杖を完成させる必要はありません。装備更新は、**14階まで届く杖**と**その先で必須戦闘を短くする杖**の二段階で考えます。不戦のロザリオで移動を短縮できる区間は通り、素材やパンが必要なときだけ戦闘を増やします。複雑な継承を追加したい場合は、攻略が安定してから[実践的な装備製作](practical-equipment.html)を参照してください。
