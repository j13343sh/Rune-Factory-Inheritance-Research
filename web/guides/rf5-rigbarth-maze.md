## 本編クリア後の一晩で準備する

最初の目標は14階の竜幻石です。**ウインターロッドで14階に入り、竜幻石を持ち帰ってマジカルステッキを作る**と、最終杖の素材が揃うまで突入を遅らせずに済みます。実践条件は引継ぎあり・ハード・DLCスターターセット使用です。[春の本編攻略](rf5-spring-story-clear.html)から続けるなら、ガトリングコメットと封印対策を引き続き使えます。

| 優先 | 突入前に揃えるもの |
| --- | --- |
| 14階までの火力 | 実践で持ち込んだ杖はウインターロッド。必須戦闘用にガトリングコメットもセットする |
| 道中と戦闘の切り替え | 通過区間には不戦のロザリオ。必須戦闘が始まる前に戦闘用装備へ切り替える。封印で魔法が止まる場合は本編で用意したサイレントリングを使える |
| 町に戻ってすぐ製作 | マジカルステッキのレシピ、竜幻石以外の材料（オリハルコン、愛のうろこ、愛の結晶、棒・茎類）を確認する |
| 更新後の強化 | 歌の小ビンと10倍鉄を先に確保する。10倍鉄を使う場合は鍛冶Lv96を目安に消費RPを確認する |

実践では本編クリア後の一晩を、製作スキル上げ、レシピパンの確保、歌の小ビンと10倍鉄の収集に使いました。マジカルステッキのレシピは鍛冶Lv76の品です。レシピ未習得でパンが必要なら、通常の武器レシピパンで習得できるものを先に覚え、上級品が必要な段階では迷宮のボス報酬も利用できます。ウインターロッドの強化順・アレンジと、防具一式の細目は記録から確認できていません。

## 14階までの進み方

1. **通過できる部屋はロザリオで抜ける。** 追加の戦闘は、進行に必須の部屋か、パンなど回収目的がある場面に絞ります。
2. **ボスや必須部屋はウインターロッドとガトリングコメットで進む。** 持ち替えて射線を取り、敵が止まるか攻撃を終えたところに、前方へ落ちる火球を重ねます。すぐに撃ち切ろうとして被弾が増える場合は、一度距離を取り、発動できる隙を作ります。封印で撃てないなら先に耐性を整えます。
3. **14階で竜幻石を取ったら折り返す。** 必要な素材が揃っていれば、そのまま町に戻って杖を製作できます。火力不足で戦闘が長引く場合も、竜幻石を取れた時点で更新を優先します。

## マジカルステッキを強化して20階へ

実践では更新したマジカルステッキに歌の小ビン・10倍鉄・レアなあきかんを使用しました。強化の再現例としては、**歌の小ビンの直後に10倍鉄**を入れて魔攻を補います。レアなあきかんは効果が確認できていないため、攻略のために集める必要はありません。

再突入後も、**移動は不戦のロザリオ、必須戦闘はガトリングコメット**と役割を分けます。ボスで撃ち続けられないときは、魔攻をさらに盛る前に封印やRP切れが原因かを確認します。14階到達に使った防具で被弾に耐えられるなら、一式を作り直す時間を省けます。

実践では準備を終えた日のゲーム内18時ごろに突入し、春29日午前1時34分ごろに20階をクリアしました。開始時刻とクリア時刻はゲーム内の記録で、準備の一晩は突入前にかけています。住民への日課も並行していたため、迷宮に集中した最短記録としては扱っていません。
