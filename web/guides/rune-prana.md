## まず揃える装備

引継ぎなし・イージーで実践した構成がこの攻略の土台です。**竜骨チャージ杖を主力にし、被ダメージが厳しいところだけ防具とブローチを更新**すると、素材集めを抑えて先へ進めます。

| 部位 | 最初の目安 | 苦しくなったときの更新候補 |
| --- | --- | --- |
| 頭 | 手編みのニット | 四季のヘッドドレス、インディゴリボン |
| 体 | ラメラーベスト | パワードプロテクタ |
| 足 | ピヨピヨサンダル | スケートブーツ |
| 盾 | ナイトシールド | エレメンタルシールド以上 |

ラメラーベストの材料が足りなければ、作りやすい服に破片を入れて進めます。杖を持つと盾のステータス反映には武器種補正がかかるため、盾の表示値だけで更新を判断せず、[武器カテゴリと盾の性能反映](weapon-category-shield.html)も参照してください。

## 鍛冶・細工を上げて破片で補う

鍛冶・細工は**Lv96を目安**にします。主な理由は強化難度95の10倍鉄を使うときの消費RPです。手持ちの武器や防具を安価なカブの種で繰り返し強化して、使う方のスキルを上げます。素材レベルが高い場合もRPが増えるので、本番は低Lv素材を優先します。スキル不足などで表示が約4,000 RPに達する場合は、先にスキルを上げ、リラックスティーは不足分を補うために使います。

1. 製作時の空き枠に**左岩の破片×2、右岩の破片×1**を投入します。
2. 完成品を **左岩の破片 → 10倍鉄 → 右岩の破片 → 倍鉄** の順で強化します。
3. 一部位から試し、必要に応じて他の部位にも広げます。

左岩の破片は物理防御と毒・封印・マヒなどへの耐性、右岩の破片は魔法防御を補うのに向きます。倍鉄と10倍鉄は直前の素材に作用するので、増やしたい破片の直後に使います。靴のレシピに空き枠が少ない場合は、入る個数で十分です。

### 基礎性能も上げたいときだけ継承する

破片入りの簡単な防具を作り、それを素材に上位防具を作ってから、上位防具の性能を簡単な防具に再継承する方法があります。手編みのニットと四季のヘッドドレスを組み合わせ、破片枠と四季のヘッドドレス側の4属性耐性を両立させたい場合の候補です。同部位のレシピを使い、空き枠や既定素材を確認し、**各工程で鑑定して破片が残ったことを確かめてから**先へ進めます。強化履歴は作り直しで持ち越さないため、倍鉄類は最終品に使います。

靴は靴本体の特殊能力も候補に入るため、普段の攻略ではオートアレンジを許容し、追加できる破片だけ入れる方が手早く仕上がります。厳選する場合は[装備継承の基本](inheritance-basics.html)と[サクラカブダミー製法](dummy-method.html)を参照してください。

### 盾の花で盾を更新する

栽培できるなら、盾の種はLv1を目安に16本ほど育てます。初回の収穫を済ませ、**性能抽選を狙うのは2回目以降**にします。収穫前にセーブし、まとめて採って性能を比べます。エレメンタルシールド相当以上が出れば、ルーンシールドまで粘る必要はありません。バドの店と抽選範囲の詳しい関係や、個別の排出率は攻略の前提にしません。

## 竜骨チャージ杖を作る

第6階層まではマジックステッキを基本に進め、第7階層で火力が足りなければマジカルステッキへ更新します。表は**完成した杖への強化順**です。上位杖用にアレンジ素材を追加収集する必要はありません。

| 強化順 | マジックステッキ | マジカルステッキ |
| --- | --- | --- |
| 1 | 水竜の灰 | 歌の小ビン |
| 2 | 10倍鉄 | 10倍鉄 |
| 3 | 水竜の灰 | 歌の小ビン |
| 4 | 倍鉄 | 倍鉄 |
| 5 | 遮光石 | 遮光石 |
| 6 | 自由枠 | 自由枠 |
| 7 | 水竜の灰 | 水竜の灰 |
| 8 | 竜の骨 | 竜の骨 |
| 9 | 焼きいも | 焼きいも |

最後の焼きいもは**虹のじょうろで代用**できます。6番目は手持ちの魔攻素材などに使い、7〜9番目の並びを確保します。レアなあきかんは攻略に必要ありません。チャージは**水竜の灰の魔法と、竜の骨のコアビーム**を使い分けます。道中では安全な距離から当て、ボスには攻撃後の隙を狙います。遮光石は水竜の灰の魔法で有効な場面があります。コアビームに同じ効果が乗るかは未確認です。

## アクセサリーを持ち替える

**ボス戦のアクセサリーは、対応する属性吸収ブローチかマジックリングに付け替えます。** 属性攻撃で崩れる相手には対応ブローチを選びます。被弾を抑えられる相手にはマジックリングでチャージを短縮し、攻撃の隙に撃ち込みます。属性トラップを通るときも、まず対応するブローチを装備します。

| 装備・アイテム | 使いどころ |
| --- | --- |
| マジックリング | 杖で戦うとき。浮遊帝国城で入手できるものを利用 |
| 不戦のロザリオ | 通り抜けたい道中。全滅が必要な部屋では外す |
| 幸せの指輪・四つ葉のクローバー | 素材収集。戦闘に戻るときは必要なアクセサリーに付け替える |
| 属性吸収ブローチ | その部屋で問題になる属性に合わせて交換 |
| 魔宝のポット | HPの回復。住民の贈り物で手に入った分を使い、自作でも補う |

[属性吸収ブローチの作り方](practical-equipment.html#rf4sp-属性吸収ブローチ)に火110%、光105%、風・地・水106%の製作例があります。ルーンプラーナでは、まず必要な属性の作りやすい構成を用意すれば進められます。

回復薬は作れる方を持参します。基本レシピは**神秘のポット（調合Lv33、薬草＋白い草、HP3,000回復）**と**魔宝のポット（Lv45、薬草＋エリ草、HP50%回復）**です。

### 1階層　左右の部屋の全滅で道を開ける

フレアメイジのいる部屋と、グリーンドラゴン・ヨロイオバケのいる部屋をそれぞれ全滅させ、出てきたスイッチを両方押します。ロザリオを外し、届かない位置の敵は杖で倒します。ウーパードラゴンの風属性攻撃とマヒが苦しい場合は、風吸収とマヒ対策を優先します。

### 2階層　風と水を柱に合わせて切り替える

**風魔法の柱は風吸収、水魔法の柱は水吸収**で通ります。人食い草が密集した通路は立ち止まらず抜けます。押し戻される強風区間では、風魔法柱へのダメージ対策とは別に、移動できる進路を探します。

### 3階層　落氷に水吸収を合わせる

道中の固定魔法トラップより、クリスタルマンモスの落氷・氷山への水吸収を優先します。引き寄せや突進には距離を取り、合図の直後は近くで攻撃を続けず、離れてから杖を撃ちます。

### 4階層　炎に備え、必要なスイッチを出す

火吸収を付けて、立っているだけで削られる炎の部屋と、炎を放つ柱を通ります。**黄色と赤のスイッチは対象部屋の敵を全滅させて出し、水色は炎の柱がある部屋で押します。** 赤へは炎が回る部屋の一つ上から、右の隠し通路を続けて進みます。スイッチには押すと追加の敵が出るものもあるため、必要な色を先に確認します。ボス戦できのとの風魔法が厳しければ、風吸収に切り替えます。

### 5階層　地・水と毒を別々に対策する

**追尾する地魔法や落石には地吸収、水魔法の柱には水吸収**を使います。風で押される落石区間では立ち止まらず進みます。毒ガスの部屋は毒耐性装備か回復手段を用意します。セイレーン戦では水レーザーに水吸収を合わせ、歌の状態異常と足場にも注意します。水を吸収する相手には杖の攻撃を切り替えます。

### 6階層　光と水を優先し、物理攻撃は避ける

**連続で当たる光の柱は光吸収、水魔法の柱は水吸収**で対応します。光と水が混ざる通路では片方を装備し、もう片方の射線を避けます。闇の柱もありますが、今回の構成では光と水の対策を優先し、闇は射線を避けて通るのを目安にします。全滅が必要な部屋はロザリオを外し、ブロック越しの敵は杖で倒します。デスウォール戦はつららへの水吸収と、物理攻撃を避ける立ち位置を用意します。

### 7階層　雑魚全滅とボス別の持ち替え

道中は戦闘とスイッチが中心です。**雑魚を全滅させるとスイッチが現れる部屋**があるので、扉の先へ進めないときは不戦のロザリオを外します。たとえばモコモコたちの部屋は水色、デスオークの部屋は青のスイッチが出ます。ボスごとに吸収ブローチとマジックリングを切り替え、杖の火力が足りない段階でマジカルステッキへ更新します。

## 素材を短時間で集める

| 素材 | 主な集め方 |
| --- | --- |
| 左岩の破片・右岩の破片 | レオン・カルナクの左之・右乃から、それぞれ対応する破片を狙う |
| 倍鉄・10倍鉄 | レオン・カルナクの鉱石チロリを1ダメージ武器で複数回攻撃。10倍鉄は希少なので先に使う部位を決める |
| 水竜の灰 | アクナトレースから入手 |
| 歌の小ビン | セイレーンから入手。マジカルステッキ用に必要数を揃える |
| 竜の骨 | 復活の洞窟のエンシェントボーンを倒す |
| 遮光石 | セルフィア平原の西で採掘 |
| あやつりの糸 | マリネッタから入手。不戦のロザリオ用に出荷し、以後はトゥーナの在庫も確認 |
| すごいクズ鉄 | 鍛冶の失敗時にまれにできる。入手したら素材集め専用の武器に使う |

トゥーナが扱う素材は、一度出荷しておくと再収集の手間を減らせます。在庫を確認し、倍鉄・10倍鉄のような非取扱品は現地で集めます。

## 省ける準備と、追加する判断

最強装備、全身Lv10強化、ルーンシールド厳選、複雑な靴継承、111%吸収、極端なレベル上げ、回復魔法の育成は、攻略開始の条件にしなくて構いません。**雑魚は抜けられるがボスの攻撃で倒れるなら対応ブローチ、被弾は少ないが時間がかかるなら杖、物理で崩れるなら防具一部位**という順に、詰まった理由に合わせて足します。
